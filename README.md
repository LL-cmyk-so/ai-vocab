# AI 词汇本（AI Glossary）

> 面向零基础读者的 AI 术语白话词典：通俗理解每个词 + 快速了解 AI 整体。

## 项目目标

1. 通俗易懂地理解 AI 出现以来的常见名词
2. 让人能迅速对 AI 有个大致的整体了解

## 已定决策（2025 讨论确认）

- **结构**：五层递进 + 第 0 词总纲（自底向上：地基 → 模型本体 → 交互层 → 应用层 → 生态与前沿）
- **译名标注**：每个词统一带三字段——英文名 / 中文名 / 别名（覆盖"英文为主、中文为主、译名不统一"三种情况）
- **词间关系**：精选跳转（每词 2~5 个"讲它时必提"的词）+ 一条主线阅读路径；**不做全量关联**
- **白话解释风格**：先结论 → 必配生活类比 → 点到为止 → 成对词对照讲 → 每条约 70~120 字
- **收词标准**：常见度 + 能白话讲清；纯学术（梯度下降、反向传播）与纯产品名（ChatGPT、Sora）不收
- **工作流程**：分批起草 → 用户审改 → 关系标注 → 组装网页 → 免费托管发布

## 冻结词单（56 词）

### 第 0 词（总纲）
人工智能（AI） · 图灵测试

### 第一层：地基（AI 是怎么工作的）

## 如何更新词条（加词 / 改内容）

1. 编辑 `drafts/` 里对应批次的 markdown（或直接编辑 `web/words.json`）
2. 重新生成数据：`python3 tools/build_words.py`
3. 重新上传 `web/` 目录里的 4 个文件到托管平台（见 PUBLISH.md）
4. 朋友刷新页面即可看到更新

> 想改页面外观（颜色/字体/布局）？改 `web/style.css` 顶部的 `:root` 变量即可，上传后生效。
