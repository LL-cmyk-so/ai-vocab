## ✨ 项目特点

- **大白话解释**：每个词先用一句话讲清"是什么"，再配一个生活类比（"Token 像切积木块""RAG 像开卷考试带小抄"）
- **说到即跳转**：词条之间互相链接，讲 A 提到 B，点一下就到 B
- **日常场景 + 常见误区**：告诉你"这词在哪能碰到"、"容易搞错什么"
- **零基础学习路线**：18 步走完，从"人工智能是什么"一路学到 AGI
- **手机友好**：折叠目录树 + 搜索 + 响应式布局，手机上一样好用

## 🔧 技术结构（纯静态，零后端）

```
web/            ← 成品网站（HTML + CSS + JS + JSON）
  index.html     页面结构
  style.css      样式（主题色改 :root 变量即可换肤）
  script.js      逻辑（渲染 / 搜索 / 路由 / PWA）
  words.json     全部词条数据
drafts/         ← 词条内容源（Markdown，按批次）
tools/          ← build_words.py：词条文档 → words.json 生成脚本
```

- 纯前端静态站：无数据库、无后端、免费托管
- 支持 PWA：可安装到桌面、离线可查
