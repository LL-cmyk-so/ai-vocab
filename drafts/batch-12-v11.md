# 第十二批：新增 3 词（MoE / 数据飞轮 / Spec Coding）

> 状态：内容已完成。MoE、Spec Coding 标"进阶"；数据飞轮为日常向。

---

### MoE（混合专家）
- **英文名**：Mixture of Experts（MoE）
- **中文名**：混合专家
- **别名**：专家混合
- **层级**：模型本体
- **进阶**：是
- **白话解释**：一种模型架构：把一个大模型拆成很多个"专家"模块，每次干活只激活其中少数几个，既省算力又能把模型做得很大。DeepSeek、Mixtral 等不少知名模型都用它，是"又大又省"的关键技术。

### 数据飞轮
- **英文名**：Data Flywheel
- **中文名**：数据飞轮
- **别名**：数据回流
- **层级**：生态与前沿
- **进阶**：否
- **白话解释**：越多人用产品 → 产生越多使用数据 → 模型学得越好 → 体验更好吸引更多人 → 产生更多数据的正循环。它解释了 AI 公司为什么愿意免费/低价给大家用——用的人多，数据就多，模型就越强。
- **类比**：像滚雪球——雪球越大滚得越快，最后自己停不下来。
- **场景**：AI 产品"免费给所有人用"、新闻里说的"数据飞轮效应"。
- **误区**：数据飞轮不是"数据越多就一定越好"——还得数据质量好、处理得当，垃圾数据滚起来是灾难。
- **混淆**：和"合成数据"——飞轮靠真实用户使用产生数据，合成数据是 AI 自己生成数据，两条路。

### Spec Coding
- **英文名**：Spec Coding
- **中文名**：规格化编程
- **别名**：规格编程
- **层级**：应用层
- **进阶**：是
- **白话解释**：Vibe Coding 的进阶玩法：先用自然语言写一份详细的"规格说明"（Spec，写清楚要做什么、怎么交互、边界在哪），再让 AI 严格按规格生成代码。比纯"随感觉写"（Vibe Coding）更可控、更不容易翻车，适合稍微正式一点的小项目。
