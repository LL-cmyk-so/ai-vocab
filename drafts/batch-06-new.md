# 第六批：新增词汇（21 词）

> 状态：内容已完成（白话释义 + 类比风格，与首批一致）。
> 字段说明：进阶 = 是/否（"进阶"面向开发者，页面显示徽标）。

---

### 推理模型 / 深度思考
- **英文名**：Reasoning Model
- **中文名**：推理模型
- **别名**：深度思考模式
- **层级**：模型本体
- **进阶**：否
- **白话解释**：现在大模型的新形态，特点是"想好了再回答"——遇到问题先在内部默默推理几步，把思路展开捋一遍，再给出最终答案。就像学生做题先打草稿、再工整抄上答案。代价是更慢、更贵，但复杂问题明显更靠谱。代表有 o1、DeepSeek-R1 这类模型，日常产品里的"深度思考"按钮就是它。

### 联网搜索
- **英文名**：Web Search
- **中文名**：联网搜索
- **别名**：无
- **层级**：交互层
- **进阶**：否
- **白话解释**：让 AI"上网查资料"的能力。默认的大模型知识停留在训练时的时点，联网后它才能查到最新消息、实时价格、今天的天气。就像学霸平时靠课本，考试前专门去翻今天的报纸。注意：联网不等于全对，AI 可能引用到错误网页，重要信息仍要核对。

### AI 搜索
- **英文名**：AI Search
- **中文名**：AI 搜索
- **别名**：无
- **层级**：交互层
- **进阶**：否
- **白话解释**：一类新产品的总称：把"搜索引擎 + AI 总结"合二为一——你问问题，它先搜网页，再综合整理成一段带来源的答案（如 Perplexity、豆包的 AI 搜索）。和"语义搜索"（底层技术）不同，"AI 搜索"是用户能直接用的产品形态，特点是答案直接、附带出处。

### 用量限制 / 限流
- **英文名**：Rate Limit
- **中文名**：用量限制
- **别名**：限流、速率限制
- **层级**：生态与前沿
- **进阶**：否
- **白话解释**：服务商防止滥用和超支的规则：单位时间内最多能请求多少次、一天最多多少额度。日常里就是免费版"今日次数已达上限"；开发时调 API 会收到 429 错误。就像餐厅招牌菜限量供应——不是不让你吃，是不能敞开了吃。超了要么等、要么升级付费。

### 电脑操控
- **英文名**：Computer Use
- **中文名**：电脑操控
- **别名**：无
- **层级**：应用层
- **进阶**：否
- **白话解释**：AI 直接操作你的电脑——看屏幕、移动鼠标、点按钮、敲键盘，替你完成订票、整理文件这类事。就像请了个远程协助，只是另一头是 AI。目前动作偏慢、偶尔出错，但"AI 自己用电脑"被认为是下一个大方向。

### AI 生成内容标识
- **英文名**：AI Content Label
- **中文名**：AI 生成内容标识
- **别名**：AI 水印
- **层级**：生态与前沿
- **进阶**：否
- **白话解释**：法规要求 AI 生成的内容（图、文、视频、语音）要有明显标识，防止以假乱真——比如角标"AI 生成"、隐形水印。就像食品配料表必须标添加剂。各国规定不同，国内已开始强制要求部分场景标注。

### MCP（模型上下文协议）
- **英文名**：Model Context Protocol（MCP）
- **中文名**：模型上下文协议
- **别名**：无
- **层级**：生态与前沿
- **进阶**：是
- **白话解释**：AI 世界的"USB 接口"——一个统一标准，让大模型用同一套方式连接各种工具和数据源（数据库、网盘、文件、外部服务）。以前每个工具要单独对接，现在按标准接一次、到处能用。2025 年各大厂商都在跟进，是 Agent 生态的地基协议。其中还有更轻量的「无状态 MCP」模式：不在服务器保留长期状态，用完即走，更安全、更好扩展。

### 思维链
- **英文名**：Chain-of-Thought（CoT）
- **中文名**：思维链
- **别名**：无
- **层级**：模型本体
- **进阶**：是
- **白话解释**：推理模型"打草稿"的过程：把一个大问题拆成一步步的推理步骤，一步步想清楚再答。就像解数学题写"因为……所以……"。很多模型的思维链过程是保密的（防止别人偷师），用户只能看到最终答案。

### ReAct
- **英文名**：ReAct
- **中文名**：ReAct
- **别名**：推理-行动循环
- **层级**：应用层
- **进阶**：是
- **白话解释**：Agent 最经典的干活方式："推理 + 行动"交替循环——想一步（先查什么）→ 做一步（调用工具）→ 看结果 → 再想下一步。就像做饭：看菜谱 → 切菜 → 尝一口 → 再调火。几乎所有 Agent 框架的基础工作模式。

### 规划
- **英文名**：Planning
- **中文名**：规划
- **别名**：任务规划
- **层级**：应用层
- **进阶**：是
- **白话解释**：Agent 接到大任务后，先把它拆成子任务清单并排好先后顺序，再逐个执行。就像项目经理开工前先列计划表。没有规划的 Agent 容易东一榔头西一棒子；规划质量直接决定复杂任务能不能完成。

### 反思
- **英文名**：Reflection
- **中文名**：反思
- **别名**：自我纠错
- **层级**：应用层
- **进阶**：是
- **白话解释**：Agent 做完一步后，回头检查自己哪里做得不对、再修正重来。就像写完作文自己通读一遍改错别字。让 Agent"越做越对"的关键能力，新一代 Agent 的标配。

### 智能体技能（Skill）
- **英文名**：Skill
- **中文名**：智能体技能
- **别名**：技能
- **层级**：应用层
- **进阶**：是
- **白话解释**：打包好的"专项能力"，装给 Agent 用——比如"查天气技能""算账单技能""检索文档技能"。就像给员工配的专业工具包。DSH 生态里的 dsh-docintel（文档检索）就是这样的技能。技能越多，Agent 能干的活越杂。

### 结构化输出
- **英文名**：Structured Output
- **中文名**：结构化输出
- **别名**：JSON 输出
- **层级**：交互层
- **进阶**：是
- **白话解释**：让 AI 按固定格式（通常是 JSON）输出，而不是自由文本——程序拿到就能直接解析使用。就像让你填表格而不是写作文。开发接入 AI 的标配能力，配合工具调用能让程序稳定工作。

### 流式输出
- **英文名**：Streaming
- **中文名**：流式输出
- **别名**：流式响应
- **层级**：交互层
- **进阶**：是
- **白话解释**：AI 一边生成一边把内容推给你——就是你看到的"打字机效果"：字一个个蹦出来。而不是等全部生成完一次性显示。体感响应快得多，也是大模型接口的默认模式。

### 温度
- **英文名**：Temperature
- **中文名**：温度
- **别名**：无
- **层级**：模型本体
- **进阶**：是
- **白话解释**：控制 AI 回答"随机性"的旋钮（0~2）：调低=保守稳定、每次回答都差不多；调高=更有创意、但可能乱说。注意：温度低≠正确，只是更稳定——"一本正经胡说"（幻觉）和温度无关，调最低也防不了编造。

### 系统提示词
- **英文名**：System Prompt
- **中文名**：系统提示词
- **别名**：无
- **层级**：交互层
- **进阶**：是
- **白话解释**：开发者预设的"全局指令"，在对话开始前就定好 AI 的角色、规则、能力边界，用户一般看不到也改不了。就像员工入职时的岗位守则；而普通"提示词"是每次对话时说的话。两者不是一个东西。

### 分块
- **英文名**：Chunking
- **中文名**：分块
- **别名**：文本切分
- **层级**：交互层
- **进阶**：是
- **白话解释**：把长文档切成小块，再送进检索（RAG）流程——因为模型每次能看的内容有限。块切多大、怎么切，直接影响检索质量：太大容易夹带无关内容，太小丢失上下文。是搭 RAG 必踩的一个坑。

### 全文检索（FTS5）
- **英文名**：Full-Text Search（FTS5）
- **中文名**：全文检索
- **别名**：关键词检索
- **层级**：交互层
- **进阶**：是
- **白话解释**：按关键词精确匹配的检索方式（SQLite 的 FTS5 是轻量代表）：快、准、不挑硬件，但不懂同义词和语义。和"语义搜索"正好互补——一个抠字面、一个抠意思。轻量本地 RAG 常用它当检索底座。

### 提示词缓存
- **英文名**：Prompt Caching
- **中文名**：提示词缓存
- **别名**：无
- **层级**：生态与前沿
- **进阶**：是
- **白话解释**：服务商把你重复发送的相同内容（比如长长的系统提示词）缓存起来，这部分不再重复计费——是省 token 省钱的核心机制。就像复印店把你常用的模板存了一份，下次直接印，不用重新排版。长对话、Agent 场景收益尤其明显。

### 量化
- **英文名**：Quantization
- **中文名**：量化
- **别名**：无
- **层级**：生态与前沿
- **进阶**：是
- **白话解释**：把模型的数字精度降低（比如 16 位降到 4 位），体积和显存占用大幅下降，让大模型能跑在普通电脑甚至手机上。就像把高清照片压缩成低清版——细节略有损失，但能装进手机。质量损失通常可接受，是本地部署的核心手段。

### MMLU
- **英文名**：MMLU
- **中文名**：MMLU
- **别名**：大模型多任务语言理解基准
- **层级**：生态与前沿
- **进阶**：是
- **白话解释**：最常被引用的 AI 评测集之一：从 57 个学科（天文、法律、医学、历史……）出选择题考模型，分数反映"通识水平"。厂商说"模型超过人类水平"，经常指的就是 MMLU 上的成绩。看评测时注意它考的是什么题、有没有水分。
